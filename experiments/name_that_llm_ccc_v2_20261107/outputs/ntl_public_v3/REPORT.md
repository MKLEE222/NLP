# 强公开方案补测：同折内部评估达到 55.64%

日期：2026-11-07。已补跑公开 StyleGrams 组件、公开外部数据消融、Qwen 冻结骨干分类头、分组残差和不完整批次压力检查。最强固定候选 Q1 的五折 prompt 分组 OOF 平衡准确率为 **55.64%**，同折此前 V2 为 **35.93%**，增加 **19.71 个百分点**。

## 复现对象与边界

直接从 Kaggle 官方公开源码接口取得 [Two-Stage LoRA & Hungarian](https://www.kaggle.com/code/saddamaditya/name-that-llm-two-stage-lora-hungarian) v1，源码哈希、依赖列表保存在 `reference_manifest.json`。其完整推理使用10个数据集、8个训练/特征 Notebook 输出和4个基础模型来源，包含8B/14B LoRA、多骨干、Gaussian 头和后处理。当前缺少完整适配器与骨干组合，**公开榜0.604的整套方案尚未复现**。另一个更高分 Notebook 的公开源码接口返回404，未用页面分数替代复现结果。

本轮提取并检查了原源码中的 StyleGrams、形状/功能词视角、稀疏 prompt 均值中心化、文本距离分组函数，没有执行整个外部 Notebook。Qwen 使用本机现有 **Qwen2.5-7B-Instruct**，截断至20层，提取第6/20层均值。相较公开基座模型，指令微调权重与NF4量化属于显式资源适配；Qwen 分组采用公开 StyleGrams 的文本距离规则，未复现原方案的 GLM 混合距离分组。既有 CCC 源码和前两轮协议未改动。

## 固定方法与五折结果

沿用第二轮完全相同的5个外层 prompt 分割和官方2,699行样本。特征变换和分类头只在各折训练分割拟合；冻结 Qwen 特征无标签提取并缓存。外部数据仅加入训练。推理阶段的分组只读取待预测批次文本，不读取真 prompt ID 或标签，不施加每组每模型一条的约束。

| 固定方法 | OOF 平衡准确率 | 相对同折 V2 |
|---|---:|---:|
| 既有 V2：TF-IDF＋85文体特征，SVM | 35.93% | — |
| P0：公开四视角 StyleGrams，官方训练数据 | 37.04% | +1.11 pp |
| P1：P0＋加权外部 Claude 文本 | 38.79% | +2.86 pp |
| P2：P1＋恢复分组后的残差分类 | 43.49% | +7.56 pp |
| Q0：冻结 Qwen 特征＋独立分类头 | 41.78% | +5.86 pp |
| **Q1：冻结 Qwen＋恢复分组残差分类头** | **55.64%** | **+19.71 pp** |
| E：P1与Q0概率固定各半融合 | 42.45% | +6.52 pp |

Q1 五折为52.78%、59.81%、57.30%、53.15%、55.19%；其 OOF BA 的 prompt bootstrap95%区间为[53.67%,57.65%]，相对V2的成对95%差值区间为[+17.64,+21.71] pp。六候选单侧Bonferroni调整后，Q1相对V2的重采样下界为+17.15 pp。没有针对外层结果搜索权重或阈值。

四视角字符/词/形状/功能词特征带来有限改进；外部数据使P0再增加1.74 pp。大部分提升来自冻结大模型表征与去除同题内容方向后的分类。Q1本身只在官方训练折训练分类头，未用新增Claude数据。固定50/50简单融合没有超过Q1，保留其失败记录。

这些结果属于已暴露训练语料上的内部研究评估。公开榜和私榜仍需单独验证；重复使用同一数据集进行研究，以及固定预测条件下的bootstrap，限制了对未知分布的推断。55.64%不能直接与公开榜0.604相减或换算排名，也不能据此判断获奖。

## 外部数据与泄漏审计

[seyitkaangunes/ntl-extra-api-passages](https://www.kaggle.com/datasets/seyitkaangunes/ntl-extra-api-passages)版本2，CC BY4.0。4,998条文本，覆盖1,000个新prompt、五个Claude标签；四类各1,000条，fable-5为998条。公开作者说明生成prompt为新题，过滤了官方训练主题；这项语义独立性是来源声明，本轮没有把ID不同当作独立性证明。

与全部官方文本做忽略大小写及空白的精确重合检查，发现0条。每折每个新增类别的总样本权重保持与原官方训练折该类数量一致，其中原样本占一半，外部样本占一半；其余13类保留原权重。五折权重断言全部通过。未生成付费API文本，未读取隐藏测试标签。

完整公开集成需要合并多来源并筛选覆盖12+标签的外部prompt；本轮单来源只有五标签，因此P1/P2明确是单来源消融，不声称逐项复现该集成的数据处理。

## 不完整批次检查

官方隐藏测试类别数量不均，因此另按预声明协议，在第一外层验证折构造两个删减批次。拟合不变、阈值不变；类别标签只用于构造偏移情形与评分，没有进入分组或预测。

| 单折诊断情形 | 文本数 | V2 | Q0独立预测 | Q1分组预测 |
|---|---:|---:|---:|---:|
| 每行以50%概率保留 | 291 | 36.09% | 43.66% | **50.58%** |
| 前9类保留25%、后9类保留75% | 261 | 41.06% | 49.97% | **56.80%** |

同一批次内分组版本仍有提升，降低了收益完全依赖完整18行组的担忧。这只是单折压力诊断；隐藏测试的真实prompt覆盖、簇可恢复性和生成设置依旧未知。Q1在无法形成2–18行合格组时回退Q0，分组在单条预测中自动关闭。

## 可使用产物与资源

`Qwen_plain_centred_heads.joblib`约2.3MB，包含全官方训练数据拟合的独立及中心化分类头、标准化器和骨干哈希。需要现有的`D:/models/qwen2.5-7b`骨干，头文件不是完整7B模型。已完成模型保存/加载预测一致性检查，实际跑通官方3行样例的完整骨干推理与`id,model` Parquet输出；该样例不提供隐藏测试成绩，未提交Kaggle。

```powershell
python outputs\ntl_public_v3\predict_qwen.py input.csv D:\models\qwen2.5-7b outputs\ntl_public_v3\Qwen_plain_centred_heads.joblib output.parquet
```

输入为`id,text`的CSV。预测批次整体参与无标签分组，改变批次组成可能改变中心化预测，应保留整批推理协议。

本机12GB显存通过NF4双量化、bf16计算容纳20层骨干。官方语料特征提取与完整分片哈希约173秒，StyleGrams五折约358秒，Qwen分类头重新拟合约37秒。为核对缓存与计时，固定分类头进行一次确定性重放，分数和每折诊断与初跑完全一致。所有四个本地权重分片SHA-256、特征/协议/脚本哈希均已记录。
