# Iteration 2: fixed nested prompt-group evaluation

Frozen 2026-11-07 after iteration 1. All official training data have now contributed to research decisions; results here measure internal prompt generalization and are not a new untouched test.

Sort 150 prompt IDs, permute with default_rng(20261110), split into five outer folds using numpy.array_split. In each outer training partition sort its prompt IDs, permute with seed 20261110+fold, reserve first 24 groups as inner development, fit on the remaining groups. Every vectorizer/scaler/classifier fits only on its corresponding fit partition. Outer refitting uses all 120 outer-training groups. No evaluation prompt IDs feed inference or assignment.

Fixed comparison: B0 from iteration 1 (char TFIDF 1–5 max250000, word1–2 max100000, min_df2, sublinear_tf, 15 standardized style features at weight0.1, balanced LR C2); V1 uses richer deterministic style features at weight0.15 and LR C2; V2 uses V1 features and balanced LinearSVC C0.5; V3 averages 85% V1 probability and 15% frozen MiniLM-embedding LR C1 probability. No Hungarian or A1 prototype candidate. Rich style feature definitions are fixed by the accompanying code before this evaluation. MiniLM is local all-MiniLM-L6-v2 revision1110a243fdf4706b3f48f1d95db1a4f5529b4d41; frozen mean of first/last160-word view embeddings, max_seq_length256. If it cannot load locally, V3 is explicitly blocked and excluded, never substituted silently.

Selection: inner prompt-cluster paired bootstrap 1000 resamples seed20261120+fold. A candidate qualifies only if one-sided lower percentile 0.05/3 >0 over B0. Select highest inner BA qualifying candidate, otherwise B0. Refit selected configuration on all outer-training data, score outer fold once. Also score the four fixed outer models as descriptive ablations. Primary endpoint is balanced accuracy of the nested selected out-of-fold predictions compared with B0. Summarize per-fold and pooled scores, 2000 prompt-cluster paired-bootstrap intervals, class recalls and selected models. These internal intervals are descriptive after previous research exposure to the dataset.

No tuning against outer results, no hidden test or leaderboard, no external passages. CCC remains a task-level evidence-authority gate inspired by the verified source; this iteration does not claim frozen-core integration. The original research project and iteration1 artifacts remain frozen.
