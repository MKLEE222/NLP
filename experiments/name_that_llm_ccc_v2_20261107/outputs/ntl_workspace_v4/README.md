# Workspace grouped residual correction v4

Custom task integration developed in this workspace. Frozen Qwen grouped-residual base + prompt-cross-fitted margins + compact raw/residual/style features + regularized boosting. Optional clipped/shrunk dual-booster correction and support fallback are evaluated separately. Existing algorithms and public components retain their source attribution; global academic novelty is unestablished.

Guarding and dual averaging did not improve the point estimate. A single-fold class-biased batch reduces primary BA relative to base, so drift robustness is not established.

Same five outer folds as iteration2/3, seed20261110. Each outer training partition has a separate inner24-prompt calibration split for early stopping. Corrector-training base probabilities are generated by three-way prompt cross-fitting inside that partition. No previous outer OOF predictions train a meta model. Models refit on all outer training prompts using only the inner-selected tree counts. Shared base probabilities reproduce iteration3 within numeric tolerance. Every early-stopping margin reconstruction was checked against library-reported validation logloss.

This folder sits beside `ntl_public_v3`, `ntl_ccc_v2` and `ntl_ccc_killtest` in the existing harness. Obtain official data separately and reproduce the pinned Qwen feature cache from iteration3 first. From the root containing `outputs` and `work`:

## Deployment-identity audit patch

The active predictor now requires `verified_encoder_manifest.json` alongside the current local model. It verifies the actual model directory, tokenizer, encoder source and cached feature contents before reuse. The distributed verification manifest binds the already-built local artifact identified in `model_manifest.json`. Rebuilding or replacing a model requires a new verification/binding step; the earlier build commands alone are not a complete portable deployment workflow. The original-machine anchor audit is recorded in `../ntl_award_audit/bind_verified_encoder.py`.
