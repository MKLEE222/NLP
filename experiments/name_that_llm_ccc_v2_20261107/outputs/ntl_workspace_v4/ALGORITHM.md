# 工作区分组残差校正器

工作名称：Workspace grouped residual correction，版本4。它是本工作区定义、实现和验证的一套组合算法；预训练骨干、线性分类器、梯度提升、交叉拟合与分组中心化均有公开先例。本文档描述具体组合接口，未将命名视为全球原创性的证明。

## 计算路径

1. 冻结Qwen编码，得到每条文本的原始表示；只由当前待预测批次的文本恢复内容分组。
2. 独立分类头处理原始表示；对合格组，用组内残差分类头得到基础概率p。
3. 用严格按prompt交叉拟合的基础概率训练两个浅树校正器；XGBoost和LightGBM把log(p)作为初始margin，学习基础模型尚未解释的分类残差。
4. 两个校正器读取训练折内压缩的原始/残差表示、85项文体特征、分组几何和基础概率，不读取评估标签或真实prompt ID。
5. 两路校正增量取均值，逐类截断到[-1,1]，缩小到0.25倍；只有分组合格且位于训练表示支持范围时启用。

\[
\delta(x)=\operatorname{clip}\left((f_{\rm XGB}(x)+f_{\rm LGB}(x))/2,-1,1\right),
\qquad
p_{\rm workspace}(y\mid x)
=\operatorname{softmax}\{\log p(y\mid x)+0.25\,g(x)\,\delta(x)\}.
\]

其中g(x)由无标签分组和训练分位支持边界决定。g=0时输出基础概率。支持边界和投影仅在训练分割拟合。校正器使用的是基础模型未见过该prompt时产生的概率，避免用训练集高置信度作为元模型的捷径。

上式对应注册主模式`WORKSPACE`。实测后推荐的工程默认模式`XGB_FULL`保留同样的交叉拟合、双视角特征、正则和内部早停，使用单路XGB增量，输出`softmax(log(p)+f_XGB(x))`。它对每行启用校正，支持域回退由`WORKSPACE`模式提供。各模式的结果和选择依据在`REPORT.md`，预注册主终点保持原样。

## 抑制过拟合的具体措施

- 外层按prompt分组评分；内部开发组只负责早停，外层不参与轮数或权重选择。
- 三路prompt交叉拟合产生纠错训练margin；训练和外层分别重建完整基础模型。
- 64维PCA坐标压缩高维表示；浅树、最小叶样本/Hessian、行列采样、L1/L2正则。
- 校正幅度截断、固定收缩系数、支持域回退；参数在结果可见前固定。
- 与纯树、普通概率融合、无约束纠错、去掉支持域回退分别比较，以确认哪个组件确有价值。

这些约束控制学习容量及信息使用；是否减轻本任务的过拟合，由内外层误差、损失、差值区间和删减批次诊断来判断。新增树模型本身不提供泛化保证。

## 来源与研究贡献

Qwen骨干和公开StyleGrams分组函数沿用第三轮的来源记录；LightGBM/XGBoost使用各自官方库。本轮自定义的是共同原始/残差坐标、交叉拟合margin、双树受限校正及支持域回退的完整工程接口。需要更广的同类方法检索和独立数据证据，才能判断能否形成学术方法贡献。当前实验不将收益归因于TQA、BRFP、SlotShift或CCC原算子。
